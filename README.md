# BKMUN

Сайт независимой молодёжной инициативы BKMUN на английском, казахском и русском языках.

Включает видеоэкран выбора языка, главную страницу, страницу конференции 3–4 октября 2026 года, Delegate Hub, локальный чек-лист и календарный файл. Используется HTML, CSS и JavaScript без сторонних зависимостей и без серверной базы данных.

## Публикация на Vercel

1. В Vercel выберите **Add New → Project** и импортируйте репозиторий `Batyrbro-55/BKMUN`.
2. Оставьте **Root Directory** в корне репозитория (`./`).
3. Нажмите **Deploy**.

Настройки уже заданы в `vercel.json`: Framework Preset — **Other**, Build Command — `node generate-pages.cjs`, Output Directory — `dist`. Установка пакетов и переменные окружения не требуются. Не выбирайте Next.js и не задавайте `dist` как Root Directory.

## Локальный запуск

Нужен современный Node.js (20 или новее).

```sh
npm run build
npm test
npm run dev
```

Откройте `http://127.0.0.1:4173`. Команда `npm install` не нужна.

## Файлы

- `dist/index.html` — экран выбора языка и главная.
- `dist/app.js` — переводы и поведение главной.
- `dist/style.css` — основной дизайн.
- `generate-pages.cjs` — исходники и переводы страниц конференции и Delegate Hub, генерация `.ics`.
- `dist/en/`, `dist/kk/`, `dist/ru/` — сгенерированные страницы.
- `dist/pages.js` — переключение языка и чек-лист.
- `dist/pages.css` — оформление дополнительных страниц.
- `dist/assets/` — изображение, логотип и собранное видео.
- `media/` — части исходного видео; сборка объединяет их и проверяет SHA-256. Это не требует сети.
- `scripts/` — проверки ссылок, языковых полей, календаря и сохранения чек-листа.

Редактируйте текст дополнительных страниц в `generate-pages.cjs`, затем запускайте `npm run build`. Прямые правки сгенерированных HTML будут перезаписаны сборкой.

## Данные и ссылки

Регистрация открывает внешнюю Google-форму. Новости ведут в `https://t.me/bkmun2026`. Прогресс чек-листа хранится в `localStorage` только на устройстве посетителя. Календарь содержит событие на весь день 3–4 октября; время заседаний не выдумано.

Фото и биографии команды, неподтверждённые комитеты и точное расписание не добавлены. После утверждения программу можно обновить в генераторе.

Проект готов для самостоятельного размещения; учётные данные и служебные настройки Sites в репозиторий не включены.
